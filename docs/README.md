# What This Folder Is

This `docs/` folder is the **source for this repo's GitHub Pages website**
— Jekyll configuration and a site page that GitHub builds automatically
into a live site. It is *not* project documentation — for that, see the
main `README.md` at the repo root, which this site mirrors.

## Files Currently In Use Here

| File | Purpose |
|---|---|
| `_config.yml` | Site-wide settings: title, description, and theme (`theme: jekyll-theme-slate`). |
| `index.md` | The site's only page: mirrors the repo's README. Front matter (`layout: default`, `title: ...`) plus content below it. |

See any other repo's `docs/README.md` in this organization for the fuller
version of this file, including the list of other Jekyll file types (
`_layouts/`, `_includes/`, `assets/`, etc.) that might get added here later.
